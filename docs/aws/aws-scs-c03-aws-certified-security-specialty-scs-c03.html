What This Exam Validates

The AWS Certified Security Specialty certification exam validates advanced technical skills and targeted knowledge in security topics including data protection, identity and access management, infrastructure security, and incident response within complex cloud environments. Certified by AWS, this specialty certification assesses practical cloud security expertise across multiple multi-account cloud deployments while maintaining demanding standards over a duration of 170 minutes.

Who Should Take This Exam

Cloud security professionals, architects, and administrators with practical experience securing AWS workloads and data environments should take this specialty exam to validate their technical expertise.

Skills You Should Be Ready to Demonstrate

  • Detection
  • Incident Response
  • Infrastructure Security
  • Identity and Access Management
  • Data Protection
  • Security Foundations and Governance

How to Prepare

Review the official exam guide domains and objectives carefully during your study period. Focus your preparation time on the practical implementation of security controls, monitoring solutions, incident response plans, and identity strategies across multiple cloud accounts to ensure adequate readiness for the 170-minute exam duration.

Domain Study Guidance

Detection: Study Guidance

This domain focuses on designing and implementing monitoring, logging, and alerting solutions for AWS accounts and organizations while troubleshooting security observability setups to ensure complete network and resource visibility.

  • Design and implement monitoring and alerting solutions for an AWS account or organization
  • Design and implement logging solutions
  • Troubleshoot security monitoring, logging, and alerting solutions

Incident Response: Study Guidance

This domain covers thorough incident response planning, test execution methodologies, and actual response management procedures during security events to maintain operational integrity and mitigate potential threats effectively across the cloud infrastructure.

  • Design and test an incident response plan
  • Respond to security events

Infrastructure Security: Study Guidance

This particular domain involves designing, implementing, and troubleshooting distinct security controls for compute workloads, network edge services, and overall network configurations to safeguard cloud architectures against external vulnerabilities and unauthorized access attempts.

  • Design, implement, and troubleshoot security controls for network edge services
  • Design, implement, and troubleshoot security controls for compute workloads
  • Design and troubleshoot network security controls

Identity and Access Management: Study Guidance

This specific domain addresses strong authentication and authorization strategies across numerous cloud services, covering the complete lifecycle of design, implementation, and troubleshooting to manage user access securely throughout the enterprise environment.

  • Design, implement, and troubleshoot authentication strategies
  • Design, implement, and troubleshoot authorization strategies

Data Protection: Study Guidance

This domain encompasses important controls for data in transit, data at rest, and the thorough protection of confidential data, credentials, secrets, and cryptographic key materials across multiple cloud storage tiers and operational workloads.

  • Design and implement controls for data in transit
  • Design and implement controls for data at rest
  • Design and implement controls to protect confidential data, credentials, secrets, and cryptographic key materials

Security Foundations and Governance: Study Guidance

This domain focuses heavily on deploying and managing cloud accounts centrally, implementing secure cloud deployments consistently across the organization, and evaluating the compliance status of various cloud resources against established baselines.

  • Develop a strategy to centrally deploy and manage AWS accounts
  • Implement a secure and consistent deployment strategy for cloud resources
  • Evaluate the compliance of AWS resources

Exam-Day Guidance

Manage your time effectively across the full 170-minute duration. Read each question carefully to identify the specific security requirements for AWS resources before selecting your final answer.
