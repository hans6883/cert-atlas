What This Exam Validates

The Microsoft Azure AI Fundamentals certification exam covers artificial intelligence concepts, capabilities, and the implementation of AI solutions by using Microsoft Foundry. Certified by Microsoft, this examination tests your fundamental understanding of fairness, reliability, safety, privacy, security, and prompt engineering principles across modern cloud workloads, requiring a passing score of 700 on a scale ranging from 1 to 1000.

Who Should Take This Exam

This exam is suited for individuals at the beginning of their career in AI solution development. Candidates need conceptual knowledge of AI solutions in Azure, along with familiarity with Python coding syntax, programming techniques, and Azure resources.

Skills You Should Be Ready to Demonstrate

  • Fairness considerations
  • Reliability and safety
  • Privacy and security
  • Prompt creation
  • Model deployment
  • Chat client application

How to Prepare

Review the official study guide and practice assessments on AI Skills Navigator carefully. Gain extensive hands-on experience using the Foundry portal to deploy models, interact with prompts, and build lightweight chat client applications by utilizing the Foundry SDK successfully during your preparation process for the 700 score.

This practical domain tests your core implementation skills for building AI solutions by using Microsoft Foundry, covering system and user prompts, model deployment procedures, and custom chat client applications.

  • Create effective system and user prompts for generative AI models
  • Deploy a model and interact with it in the Foundry portal
  • Create a lightweight chat client application by using the Foundry SDK
