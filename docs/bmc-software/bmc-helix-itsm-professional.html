What This Exam Validates

BMC Software administers the BMC Helix ITSM Professional exam to evaluate technical skills across 15 domains. Candidates face topics including BMC Helix Innovation Suite architecture, foundation data configuration, categorization, templates, and task management systems. The test also assesses expertise in BMC AR System administration, server group consoles, user access control, centralized configuration settings, and archiving processes across a 120-minute examination window.

Who Should Take This Exam

IT service management administrators, system integrators, and technical consultants operating BMC Helix ITSM applications should take this exam. Candidates should have hands-on experience configuring AR System settings, foundation data, assignment rules, and application modules.

Skills You Should Be Ready to Demonstrate

  • BMC Helix Innovation Suite and ITSM architecture
  • Foundation data and categorization configuration
  • Incident, Problem, Asset, Change, and Release Management setup
  • Task Management System and template administration
  • BMC AR System user, group, and access control management
  • Service Level Management components and archiving workflow

How to Prepare

Focus study efforts across all 15 domains outlined by BMC Software. Spend time configuring foundation data, assignment rules, and notifications within the Mid Tier interface and Application Administration Console. Practice working with BMC AR System licensing, centralized configuration parameters, and server group settings. Review Task Management System flows, email engine rules, and archiving processes to ensure technical knowledge across the complete 120-minute testing syllabus.

Domain Study Guidance

BMC Helix Innovation Suite Architecture, ITSM architecture and components: Study Guidance

This domain addresses the structure of BMC Helix Innovation Suite alongside core ITSM architecture and underlying components. Administrators examine how architectural layers interact to support service management capabilities across deployed applications and system modules.

  • Innovation Suite architectural layers
  • ITSM component relationships

Configuration of foundation data: Study Guidance

This domain covers setting up organizational structure, site information, companies, and people records in BMC Helix ITSM. Practitioners manage foundation data dependencies required before establishing functional assignment rules, product catalog items, and application operational capabilities.

  • Company and site setup
  • People record management
  • Foundation data order of operations

Configuration of categorization, assignments, notifications, and templates: Study Guidance

This section focuses on defining operational and product categorizations, assignment routing orders, notification triggers, and template structures. Practitioners configure rules that determine how records move between support organizations and assigned personnel.

  • Operational and product categorization
  • Support group assignment rules
  • System notification management

Configuration of Incident Management, Problem Management and Asset Management, Change and Release Management: Study Guidance

Candidates address module-specific administrative settings for core service management processes. Topics include setting lifecycle rules, approval paths, phase transitions, and operational options across Incident, Problem, Asset, Change, and Release Management modules.

  • Incident and Problem Management setup
  • Asset Management configurations
  • Change and Release process rules

Task Management System and Task Phase Management: Study Guidance

This domain concentrates on managing task workflows, task assignments, and phase execution orders within ticketing applications. Administrative tasks include setting up task phases to sequence activities during record resolution.

  • Task Management System configuration
  • Task phase sequencing
  • Task assignment routing

Application templates and task templates: Study Guidance

Candidates review standard application templates and reusable task templates that streamline record creation. Topics emphasize defining predefined field values, linking task groups to change or incident templates, and maintaining consistent data input.

  • Application template design
  • Task group and template association
  • Field default configurations

Email engine rules: Study Guidance

This section examines the setup and management of the BMC AR System Email Engine. Topics focus on configuring incoming email parse rules, automated ticket generation criteria, outgoing notifications, and system processing options.

  • Email Rule Engine configuration
  • Incoming mail parsing
  • Email-driven action rules

ITSM archiving process: Study Guidance

This domain covers setting up and executing data archiving policies within BMC Helix ITSM. Topics center on maintaining database performance, defining criteria for archiving historical records, and configuring underlying archiving forms.

  • Data archiving policies
  • Historical record management
  • Archiving form settings

Service Level Management, including components and roles: Study Guidance

Candidates review BMC Service Level Management architecture, service level agreements, milestones, and target definitions. Topics highlight role responsibilities, SLA tracking mechanisms, and escalation notification workflows for service targets.

  • Service level target creation
  • SLM roles and responsibilities
  • SLA milestone and escalation rules

Notifications workflow and management: Study Guidance

This domain focuses on configuring system notification mechanisms, active link triggers, and messaging defaults. System administrators manage Notification Engine parameters to deliver operational updates to internal staff and external requestors.

  • Notification Engine parameters
  • Message template customization
  • Alert trigger criteria

Basics of BMC AR System including AR System access control and user base: Study Guidance

Candidates demonstrate core knowledge of BMC Remedy Action Request System architecture, user accounts, and security concepts. Emphasis is placed on access control lists, permission groups, explicit permissions, and functional roles.

  • AR System architecture fundamentals
  • Access control structures
  • Permission groups and explicit permissions

Centralized configuration settings and AR System Licensing: Study Guidance

This domain covers managing centralized configuration components and applying application licenses. System administrators learn to modify global system parameters, manage server component settings, and allocate fixed, floating, or read license types.

  • Centralized configuration parameters
  • Server component settings
  • AR System license allocation

AR System Administration Console and AR Server Group Console: Study Guidance

Candidates explore navigation and utility management within administrative consoles. Focus areas include operating the AR System Administration Console, monitoring cluster nodes from the AR Server Group Console, and executing server maintenance.

  • AR System Administration Console
  • AR Server Group Console operations
  • Cluster node monitoring

Managing users, groups, and roles in the AR System: Study Guidance

This domain emphasizes creating user records, mapping users to security groups, and defining application functional roles. Administrators manage role hierarchies and dynamic permissions to regulate access across system components.

  • User record creation
  • Group membership assignment
  • Functional role mapping

Understand Forms and Fields: Study Guidance

Candidates analyze form types, field properties, data structures, and database mappings within AR System applications. Study focuses on identifying core, regular, join, and vendor forms alongside field attributes and display properties.

  • Form types and data structures
  • Field attributes and properties
  • Database field mappings
