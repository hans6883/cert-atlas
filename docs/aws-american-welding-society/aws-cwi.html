What This Exam Validates

The Certified Welding Inspector (CWI) exam, administered by the American Welding Society, validates expertise across a broad spectrum of welding knowledge. Candidates must demonstrate proficiency in fundamentals, processes, inspection techniques, nondestructive testing, metallurgy, calculations, qualifications, code applications, and reporting. The exam is delivered as a linear, computer‑based test at AWS‑approved or Pearson VUE centers.

Who Should Take This Exam

Professionals who perform or supervise welding inspections, such as welding engineers, quality‑control supervisors, fabricators, and safety officers with several years of hands‑on welding or inspection experience, should pursue the CWI certification.

Skills You Should Be Ready to Demonstrate

  • Welding fundamentals
  • Process terminology
  • Inspection symbols
  • Nondestructive testing
  • Metallurgy calculations

How to Prepare

Review AWS study guides and the latest welding codes, then practice with sample questions that mirror the multiple‑choice and open‑book sections. Build a reference sheet for code tables, rehearse visual examination techniques, and solve calculation problems daily. Schedule mock exams in the same linear format to manage time and become comfortable with the computer interface.

Frequently asked questions

How many questions are on the exam?

AWS does not publish the exact number of questions. The Certified Welding Inspector exam is delivered as a linear, computer‑based test that includes multiple‑choice items and an open‑book code section.

What is the passing score?

A candidate must achieve at least 72% on each part of the exam to pass. The precise scoring algorithm is not publicly disclosed beyond this percentage requirement.

How long is the exam?

The official exam duration is not specified by AWS, so candidates should allocate sufficient time to complete all sections of the linear, computer‑based format, including both multiple‑choice and open‑book code portions.

What does the exam cost?

The exam fee is $895 for AWS members and $1,195 for non‑members. Verify current fees on the AWS website before registering, and ensure you understand any applicable refund policy.
