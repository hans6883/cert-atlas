What This Exam Validates

The Elastic Certified Engineer exam, provided by Elastic, evaluates technical proficiency in managing Elasticsearch environments. It covers six domains, including installation, indexing, queries, aggregations, mappings, and cluster administration. This hands-on practical exam requires candidates to perform tasks within a live environment. As of 2026-09-01, this exam is retired, and candidates should transition to the Elastic Certified Engineer 9.3 certification path for their professional development and validation of skills. This certification remains valid for 3 years, requiring renewal to maintain your professional status.

Who Should Take This Exam

This exam is for engineers and administrators who manage Elasticsearch clusters. Candidates need practical experience with cluster configuration, data indexing, and query optimization. It is suitable for those who work directly with the Elastic Stack in production environments and require formal validation of their technical capabilities.

Skills You Should Be Ready to Demonstrate

  • Installing and configuring Elasticsearch
  • Indexing and managing data
  • Executing complex queries
  • Building data aggregations
  • Defining mappings and text analysis
  • Performing cluster administration

How to Prepare Before Retirement

Review the official Elastic study documentation to understand the hands-on requirements. Practice performing tasks in a live Elasticsearch environment, as the exam format is entirely practical. Focus on the six domains, ensuring you can handle indexing, query DSL, and cluster management tasks under time constraints. The exam lasts 180 minutes and costs $400, so efficient, hands-on practice is necessary to succeed in the live environment. Ensure you are comfortable with the environment before your session.

Domain Study Guidance

Installation and Configuration: Study Guidance

This domain covers the setup and configuration of Elasticsearch nodes and clusters. It focuses on the practical application of deployment settings and architecture requirements for a functional environment, ensuring that all nodes are correctly configured for production use.

  • Node role configuration
  • Cluster formation

Indexing Data: Study Guidance

This domain involves the methods for bringing data into Elasticsearch. It covers the use of document APIs, connectors, and ingest tools to prepare data for search and analysis, ensuring that all incoming data is properly indexed and searchable.

  • Document indexing
  • Ingest pipeline usage

Queries: Study Guidance

This domain addresses the use of Query DSL to retrieve and filter data. It requires understanding query and filter contexts to perform precise searches within the cluster, enabling users to extract relevant information from their indexed datasets efficiently.

  • Query DSL syntax
  • Query vs filter context

Aggregations: Study Guidance

This domain focuses on summarizing data using metric, bucket, and pipeline aggregations. It involves building complex analytics to gain insights from indexed documents, allowing administrators to visualize trends and patterns within their stored data structures effectively.

  • Metric aggregation types
  • Bucket aggregation logic

Mappings and Text Analysis: Study Guidance

This domain covers defining how documents and fields are stored. It includes explicit mapping, dynamic mapping, and the use of runtime fields to manage data structures, ensuring that data types are optimized for search and storage performance.

  • Explicit mapping definition
  • Field data types

Cluster Administration: Study Guidance

This domain involves managing cluster health, shard allocation, and node roles. It requires knowledge of maintaining high availability and performance in a distributed system, ensuring that the cluster remains stable and responsive under various operational conditions.

  • Shard allocation awareness
  • Cluster monitoring

Exam-Day Guidance

The exam is a hands-on practical assessment conducted in a remote proctored environment. You will interact with a live Elasticsearch environment to complete tasks. Ensure your workspace meets all technical requirements before starting the 180-minute session.

Frequently asked questions

How many questions are on the exam?

The exam consists of hands-on practical tasks performed within a live Elasticsearch environment. It does not use traditional multiple-choice questions, focusing instead on your ability to execute specific administrative and analytical tasks in a real-world scenario.

What is the passing score?

Information regarding a specific numerical passing score is not provided. Candidates are evaluated based on their successful completion of the hands-on practical tasks within the live environment, ensuring they demonstrate the necessary technical skills required for the certification.

How long is the exam?

The exam duration is 180 minutes. During this time, you must complete the required hands-on practical tasks in a live Elasticsearch environment under remote proctoring, ensuring you manage your time effectively to address all the assigned technical challenges.

What is the cost of the exam?

The exam price is $400. This fee covers the remote proctored, hands-on practical assessment of your skills in managing and querying Elasticsearch, providing a formal validation of your technical expertise in the Elastic Stack.
