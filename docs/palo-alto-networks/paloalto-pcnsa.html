Historical PCNSA Scope

The Palo Alto Networks Certified Network Security Administrator certification was administered by Palo Alto Networks to validate administrative knowledge of next-generation firewalls. This exam retired on 2025-01-31, and Network Security Professional / Network Security Analyst / Next-Generation Firewall Engineer is the named replacement. The program covered device management, object maintenance, policy evaluation, traffic security, and user identification.

Who PCNSA Was For

Network administrators, security engineers, and support personnel who configure, manage, and maintain Palo Alto Networks next-generation firewalls should pursue the Network Security Professional / Network Security Analyst / Next-Generation Firewall Engineer successor path.

How to Reuse Your Preparation

To properly and carefully prepare for the replacement path, candidates should study official PAN-OS administration guides, review best practices for securing administrative access, explore core security concepts, and practice configuring features such as App-ID, User-ID, and device settings using next-generation firewalls during their routine study sessions.

Frequently asked questions

How many questions are on the exam?

The exam contains 75 total questions delivered in a linear format. Question types consist of multiple choice and multiple select items based on PAN-OS administration concepts.

How long is the exam?

Candidates are given a duration of 80 minutes to complete all 75 questions on the exam. Managing time effectively across the domains is important during this period.

What is the exam price?

The exam registration fee is priced at 155.0 USD for all test takers. Candidates should verify current pricing directly with the test delivery provider before scheduling their replacement certification.

What is the replacement for this retired exam?

The verified successor is Network Security Professional / Network Security Analyst / Next-Generation Firewall Engineer. Every candidate looking for the path forward should register for this successor rather than the retired credential.
