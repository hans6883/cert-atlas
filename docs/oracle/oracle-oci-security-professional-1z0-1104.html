Historical 1Z0-1104-23 Scope

Certified by Oracle, the Oracle Cloud Infrastructure 2023 Security Professional exam covered security architecture, identity management, network security, data protection, security operations, threat management, and compliance across cloud environments. This exam is retired as of 2024-08-31 and has been replaced by 1Z0-1104-24 as the official successor, giving candidates a total of 60 questions to complete during the evaluation.

Who 1Z0-1104-23 Was For

Cloud security professionals and infrastructure engineers with practical experience securing enterprise workloads. Candidates must shift their focus to the 1Z0-1104-24 exam to validate current Oracle Cloud Infrastructure security expertise.

How to Reuse Your Preparation

Since this exam is retired, do not attempt to register for it or purchase it for $245.00 USD. Prepare exclusively for the successor 1Z0-1104-24 instead. Core OCI security principles, encryption standards, and shared security models transfer directly, but you must study updated documentation for current service configurations.

Frequently asked questions

How many questions are on the exam?

The retired exam format consisted of exactly 60 multiple choice and multiple select questions delivered in a linear format during the allotted testing time provided to every candidate.

What is the passing score?
