1.0 Handling date, time, text, numeric and boolean values Weight not published
  • 1.1Use primitives and wrapper classes including Math API, parentheses, type promotion, and casting to evaluate arithmetic and boolean expressions
  • 1.2Manipulate text, including text blocks, using String and StringBuilder classes
  • 1.3Manipulate date, time, duration, period, instant and time-zone objects using Date-Time API
2.0 Controlling Program Flow Weight not published
  • 2.1Create program flow control constructs including if/else, switch statements and expressions, loops, and break and continue statements
3.0 Utilizing Java Object-Oriented Approach Weight not published
  • 3.1Declare and instantiate Java objects including nested class objects, and explain the object life-cycle including creation, reassigning references, and garbage collection
  • 3.2Create classes and records, and define and use instance and static fields and methods, constructors, and instance and static initializers
  • 3.3Implement overloading, including var-arg methods
  • 3.4Understand variable scopes, use local variable type inference, apply encapsulation, and make objects immutable
  • 3.5Implement inheritance, including abstract and sealed classes. Override methods, including that of Object class. Implement polymorphism and differentiate object type versus reference type. Perform type casting, identify object types using instanceof operator and pattern matching
  • 3.6Create and use interfaces, identify functional interfaces, and utilize private, static, and default interface methods
  • 3.7Create and use enumerations with fields, methods and constructors
4.0 Handling Exceptions Weight not published
  • 4.1Handle exceptions using try/catch/finally, try-with-resources, and multi-catch blocks, including custom exceptions
5.0 Working with Arrays and Collections Weight not published
  • 5.1Create Java arrays, List, Set, Map, and Deque collections, and add, remove, update, retrieve and sort their elements
6.0 Working with Streams and Lambda expressions Weight not published
  • 6.1Use Java object and primitive Streams, including lambda expressions implementing functional interfaces, to supply, filter, map, consume, and sort data
  • 6.2Perform decomposition, concatenation and reduction, and grouping and partitioning on sequential and parallel streams
7.0 Packaging and deploying Java code and use the Java Platform Module System Weight not published
  • 7.1Define modules and their dependencies, expose module content including for reflection. Define services, producers, and consumers

8.0 Managing concurrent code execution Weight not published
  • 8.1Create worker threads using Runnable and Callable, manage the thread lifecycle, including automations provided by different Executor services and concurrent API
  • 8.2Develop thread-safe code, using different locking mechanisms and concurrent API
  • 8.3Process Java collections concurrently including the use of parallel streams
9.0 Using Java I/O API Weight not published
  • 9.1Read and write console and file data using I/O Streams
  • 9.2Serialize and de-serialize Java objects
  • 9.3Create, traverse, read, and write Path objects and their properties using java.nio.file API
10.0 Accessing databases using JDBC Weight not published
  • 10.1Create connections, create and execute basic, prepared and callable statements, process query results and control transactions using JDBC API
11.0 Implementing Localization Weight not published
