Historical ACA-DB Scope

The ACA Database Associate (ACA-DB) certification from Alibaba Cloud covered database fundamentals, ApsaraDB RDS, NoSQL, data migration, and high availability configurations. This exam is officially retired as of 2025-03-31. Alibaba Cloud has not named a successor for this credential. Candidates seeking current certification paths should consult the official Alibaba Cloud education portal for the latest available programs and professional guidance regarding their cloud database learning journey and technical development.

Who ACA-DB Was For

This retired exam was intended for database administrators and cloud engineers managing database workloads. It required knowledge of relational and NoSQL database services, migration strategies, and high availability configurations within the Alibaba Cloud environment to ensure operational success for various enterprise applications.

Skills You Should Be Ready to Demonstrate

  • Database fundamentals
  • ApsaraDB RDS management
  • NoSQL database operations
  • Data migration techniques
  • High availability configurations
