ACA-Security Retired: What Replaced It and What Carries Over

ACA-Security

Alibaba Cloud

Retired exam

ACA-Security was retired on May 13, 2025

Alibaba Cloud retired ACA-SECURITY on 2025-05-13. CSA-C01 is the named replacement path.

Prepare for CSA-C01: Alibaba Cloud Certified Associate: Cloud Security Engineer

Historical ACA-Security Scope

The Alibaba Cloud Security Associate certification historically covered cloud security fundamentals, identity management, data encryption, security products, and incident response across a total of 60 questions with a maximum duration of 120 minutes. Certifying body Alibaba Cloud officially retired this exam on May 13, 2025. Its verified direct successor is CSA-C01, which is the current standard for cloud security professionals.

Who ACA-Security Was For

Cloud administrators, security engineers, and IT professionals seeking to validate their knowledge of Alibaba Cloud security controls and products. Candidates should focus their efforts on the current CSA-C01 certification path to maintain their professional credentials.

Skills You Should Be Ready to Demonstrate

  • Cloud Security Fundamentals
  • Identity and Access Management
  • Data Encryption
  • Security Products
  • Incident Response

How to Reuse Your Preparation

Do not attempt to schedule or study specifically for this retired exam. Direct your preparation toward the verified successor, CSA-C01. Core security principles transfer completely, but you must align your study plan with the current official documentation and exam guides for the active credential to ensure you are ready for the new requirements.

Frequently asked questions

How many questions are on the exam?

The examination consists of a total of exactly 60 questions presented in multiple choice and multiple response formats designed to evaluate candidate proficiency in cloud security.

What is the passing score?

The evaluation uses a pass/fail grading scale where the specific numerical passing threshold is not publicly disclosed by Alibaba Cloud for this retired certification credential.

How long is the exam?

Test takers are given a total duration of 120 minutes to complete all questions on the computer-based test before the time officially expires for the candidate.

What is the successor to this retired exam?

The verified successor exam is CSA-C01, which represents the current path and official standard for candidates seeking Alibaba Cloud security certification in the modern cloud era.
