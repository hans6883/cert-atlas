Historical DEA-C01 Scope

The SnowPro Advanced: Data Engineer certification exam, administered by Snowflake, is now retired and no longer available for scheduling. Its verified successor is DEA-C02. The linear exam format historically featured 65 questions, a duration of 115 minutes, and a passing score of 65. Candidates evaluated data engineering concepts across 5 distinct domains.

Who DEA-C01 Was For

Data engineers and advanced Snowflake professionals seeking to validate technical proficiency. Candidates should focus study efforts on the successor DEA-C02, as the current program requires transition planning.

Historical Domain Guide

Data Movement: Historical Scope

This domain covers standard data movement mechanisms in Snowflake, focusing heavily on bulk loading with COPY INTO, continuous loading using Snowpipe and Snowpipe Streaming, and integrating with external cloud storage stages securely.

  • Configuring internal and external stages
  • Implementing bulk and continuous loading strategies
  • Handling data ingestion via Kafka and streaming

Performance Optimization: Historical Scope

This domain focuses intensely on optimizing query execution and warehouse performance through resource sizing, memory management, query acceleration, and effectively managing virtual warehouse queues to ensure optimal enterprise computing efficiency.

  • Reducing warehouse query queues
  • Resolving memory spillage issues
  • Scaling virtual warehouse sizes

Storage and Data Protection: Historical Scope

This domain deals extensively with storage management and data protection features built into Snowflake, including time travel, failsafe capabilities, and handling external tables for modern cloud-based data lakes effectively.

  • Managing storage metrics and usage
  • Configuring data protection features
  • Utilizing external tables for cloud storage

Security: Historical Scope

This domain addresses specific security principles within Snowflake, focusing deeply on access control hierarchies, user privileges, and object level security configurations required to protect sensitive corporate assets during standard operations.

  • Configuring security access control privileges
  • Managing table ownership and grants
  • Securing database objects

Data Governance and Privacy: Historical Scope

This domain covers broad data governance and privacy practices, ensuring proper handling of data objects and strict compliance with organizational requirements and regulatory standards within the platform ecosystem.

  • Implementing data governance policies
  • Managing privacy standards
  • Utilizing governance framework tools

Frequently asked questions

How many questions are on the exam?

The exam traditionally consists of 65 questions presented in a linear format. Question types include multiple choice and multiple select options for candidates taking the test.

What is the passing score?

The passing score for the historical exam is 65. Candidates must achieve this specific score out of the total questions administered during the linear test session.

How long is the exam?

The total duration of the exam is 115 minutes. Candidates must complete all required questions within this strictly allocated timeframe during their scheduled test session.

What is the exam price?

The standard price for registering for the certification exam is $250. This mandatory fee applies to all registrations for the official certification program administered by Snowflake.
