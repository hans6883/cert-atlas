What This Exam Validates

The UiPath Automation Developer Professional Exam is certified by UiPath and validates technical skills in advanced data manipulation, REFramework implementation, debugging, UI automation, Orchestrator management, attended automation, autopilot features, API automation, resource management, and generic automation development across modern enterprise environments during a complete 120 minutes testing session for qualified candidates.

Who Should Take This Exam

Automation developers, system integrators, and technical professionals who have hands-on experience building complex enterprise automation projects using UiPath Studio and Orchestrator platforms in their daily work.

Skills You Should Be Ready to Demonstrate

  • Advanced Data Manipulation
  • Advanced UI automation
  • REFramework implementation
  • Orchestrator management
  • Attended Automation
  • API Automation

How to Prepare

Review official documentation on Studio and Orchestrator features in depth to ensure complete readiness. Practice building projects using LINQ queries, DataTables, and the REFramework template. Test remote debugging setups and API workflows directly to achieve success during the 120 minutes allowed.

Domain Study Guidance

Advanced Data Manipulation: Study Guidance

This domain focuses on advanced data handling techniques, including utilizing LINQ queries for lists and DataTables, performing date and time parsing, executing formatting conversions, and running Invoke Method and Invoke Code activities within projects.

  • Use LINQ for Lists and DataTables.
  • Perform DateTime manipulation to parse dates, add, or substract time and convert to and from string type.
  • Use Invoke Method and Invoke Code in projects.

Debugging: Study Guidance

This domain covers troubleshooting techniques and testing protocols, specifically including remote debugging configurations, troubleshooting live builds, and profiling execution performance during automation workflow development activities across your projects.

  • Perform remote Debugging when building automation projects.
  • Profile execution - debugging

Advanced UI automation: Study Guidance

This domain deals with complex web driver usage, remote runtimes, and advanced agentic user interface automation scenarios, incorporating healing scenarios, testing mechanisms, and interactive attended execution flows within your development scope.

  • Build an UI automation using Web Driver.
  • Remote runtime
  • UiTask/UiAct — AGENTIC (healing scenarios, testing, attended scenarios)

REFramework: Study Guidance

This domain examines the Robotic Enterprise Framework template in depth, exploring producer and consumer models, dispatcher and performer structures, core template mechanisms, and the configuration of custom log fields.

  • Explain the use of the REFramework and the Dispatcher and Performer / Producer and Consumer model.
  • Describe the mechanisms of the REFramework template.
  • Use Custom Log Fields in REFramework projects.

Orchestrator: Study Guidance

This domain involves managing tenant and folder entities in Orchestrator, configuring unattended automation features, handling job priorities, allocating licenses per machine, and setting up API triggers for your enterprise infrastructure.

  • Use Tenant Entities (Webhooks, Alerts, Packages, etc) and Folder Entities (Triggers, Credential Stores, etc).
  • Use features for unattended automations (use of folders and job priorities, separation between background and foreground processes, license allocation per machine).
  • API Triggers

Attended Automation: Study Guidance

This domain covers long-running workflows, trigger-based automations, and native application event triggers designed to handle local control events and interactive user processes effectively during daily production operations and tasks.

  • Long-Running Workflows
  • Trigger-based Automation
  • UI automation Apps Native Events Triggers (Run local triggers, Stop local triggers)

Autopilot: Study Guidance

This specific domain focuses heavily on utilizing Autopilot features, understanding how artificial intelligence and advanced digital assistants are tailored specifically for general users as well as technical developers building enterprise solutions.

  • Autopilot for Everyone
  • Autopilot for Developers

API Automation: Study Guidance

This domain addresses API workflows, event triggers, and the application of the Integration Service Connector Builder to connect external systems and services together within your advanced deployment projects.

  • API Workflows
  • Explain what the Integration Service Connector Builder is.
  • Event Triggers

Resource Management: Study Guidance

This domain focuses on enterprise solutions management, along with creating and consuming structured entities using Data Service and utilizing its platform connector successfully during your system architecture design phases.

  • Solutions Management
  • Data service (Creation/Consumption of Entities)
  • Data Service platform connector

Generic Automation Development: Study Guidance

This domain tests practical tasks commonly used in automation that require combining multiple development skills, technical knowledge areas, and platform capabilities learned throughout your preparation for the exam.

  • Tasks commonly used in automation that require a combination of the skills and knowledge listed above.
  • Integrating multiple technical areas to solve complex enterprise scenarios.

Exam-Day Guidance

Manage your time carefully across the 120 minutes allowed. Read each scenario completely before answering, and rely on your hands-on practice with UiPath Studio and Orchestrator.
