What This Exam Validates

The New Relic Verified Foundation exam evaluates your knowledge of observability fundamentals, platform UI capabilities, data configuration, performance monitoring, and full stack practices. Certified by New Relic, this online unproctored multiple-choice exam is free to take and validates core telemetry and monitoring skills across various environments over a duration of 45 minutes.

Who Should Take This Exam

Engineers, developers, and administrators who use New Relic to monitor applications, infrastructure, and user experiences. Suitable for practitioners looking to validate their platform knowledge and telemetry configuration skills.

Skills You Should Be Ready to Demonstrate

  • Observability fundamentals
  • New Relic platform UI
  • Data configuration
  • Performance monitoring
  • Full stack observability

How to Prepare

Review official New Relic documentation and tutorials covering telemetry data types, monitoring agents, and NRQL queries to prepare carefully. Practice installing monitoring agents, configuring dashboards, setting up alerts, and analyzing transaction traces directly in the platform UI before taking the assessment to ensure complete success.

Domain Study Guidance

Section 1 : Observability O11y Fundamentals: Study Guidance

Covers modern web architecture trends and tools, differences between monitoring and observability, core telemetry data types, and monitoring agents in New Relic to build a strong operational base.

  • Understand modern web architecture trends
  • Distinguish monitoring and observability
  • Define core telemetry data types
  • Implement monitoring agents

Section 2 : New Relic Platform UI & Capabilities: Study Guidance

Focuses extensively on identifying reporting entities, viewing the overall environment status, and using diverse platform capabilities including APM, Browser, NRQL, alerts, logs, traces, hosts, and mobile to monitor system health effectively.

  • Identify reporting entities
  • View environment status
  • Use APM, Browser, and NRQL
  • Configure alerts and logs

Section 3 : Configuring data: Study Guidance

This domain comprehensively covers instrumentation concepts, stack layer configuration, custom data and attributes, entity and workload management, tags, and synthetics configuration to ensure complete data collection across your entire system ecosystem.

  • Configure layers of the stack
  • Add custom data and attributes
  • Manage entities, tags, and workloads
  • Configure synthetics

Section 4 : Performance Monitoring: Study Guidance

Explores data visualization using APM, errors, logs, NRQL, and Synthetics, transaction trace analysis, root cause analysis, and issue triage to help practitioners diagnose and resolve performance bottlenecks quickly.

  • Visualize data with APM and logs
  • Conduct transaction trace analysis
  • Perform root cause analysis
  • Triage and respond to issues

Section 5 : Full Stack Observability Practises: Study Guidance

This domain addresses multi-service management using filtering and tagging, alert and workflow configuration, event type NRQL queries, and core alerting concepts to maintain dependable visibility across complex distributed system architectures.

  • Manage services with filtering and tagging
  • Configure alerts and workflows
  • Write NRQL queries
  • Understand alerting concepts

Exam-Day Guidance

You have 45 minutes to complete the online unproctored multiple-choice exam. Ensure your testing environment is quiet and free of interruptions before starting your session.

Frequently asked questions

How much does the exam cost?

The New Relic Verified Foundation exam is entirely free to take. It is an online unproctored multiple-choice assessment hosted directly on learn.newrelic.com for registered users.

How long is the exam?

The exam has a strict duration of 45 minutes. You must complete all online unproctored multiple-choice questions within this allocated time limit to successfully finish the test.

How long is the certification valid?

The New Relic certification remains valid for 2 years per the official University Terms. Check with New Relic for the current certification path and renewal details.

What topics are covered on the exam?

The exam covers 5 distinct domains including observability fundamentals, platform UI capabilities, configuring data, performance monitoring, and full stack observability practices to test your knowledge.
