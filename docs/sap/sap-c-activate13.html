SAP Certified Associate — SAP Activate Project Manager has been retired

SAP no longer offers C_ACTIVATE13. SAP's own certification catalogue on learning.sap.com lists 97 bookable exam codes and C_ACTIVATE13 is not among them, and its page on SAP's training shop is gone: 'Page not found We Are Unable to Locate the Page You Requested. Dear Customer, Unfortunately, the page you are trying to reach no longer exists on the SAP Training Shop'. SAP's own definition applies: 'If an SAP Certification has been or will be retired, learners will no longer be able to book the certification exam or do an assessment to stay certified after the retirement date.' SAP publishes no retirement date and names no successor for this code; the SAP Activate project-manager certification it once carried is now sold as 'SAP Certified - Project Manager - SAP Activate' (C_ACT_2604).

No direct replacement is named in the reviewed official sources.
