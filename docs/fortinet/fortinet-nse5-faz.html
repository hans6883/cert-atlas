Historical FCP_FAZ_AD-7.4 Scope

The NSE 5 Network Security Analyst — FortiAnalyzer examination, designated by code FCP_FAZ_AD-7.4 and certified by Fortinet, covered administrative tasks and management features for FortiAnalyzer deployments across multiple domains. Fortinet officially retired this examination on 2025-10-14. Candidates seeking certification paths now pursue the NSE 6 - FortiAnalyzer 7.6 Administrator instead.
