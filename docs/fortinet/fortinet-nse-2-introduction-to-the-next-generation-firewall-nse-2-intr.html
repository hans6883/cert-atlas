What This Exam Validates

The NSE 2 - Introduction to the Next Generation Firewall exam is presented by Fortinet as part of the official training requirements. Candidates learn how a Next Generation Firewall protects corporate networks, important applications, and diverse services, and explore how modern secure network models enhance overall cybersecurity readiness across 9 extensive domains designed for security professionals.

Who Should Take This Exam

Network and security professionals looking to understand firewall policies, malware blocking, web filtering, and intrusion prevention. Candidates study the course materials and pass the online exam to earn certification active 2 years from course completion.

Skills You Should Be Ready to Demonstrate

  • Next Generation Firewall concepts
  • Firewall policies
  • User authentication
  • Malware blocking
  • Web filtering
  • Intrusion Prevention
  • Secure SD-WAN
  • SASE

How to Prepare

Review the official course agenda covering the 9 domains entirely. Complete the online exam presented at the end of the course to earn certification active 2 years from course completion. Ensure you study all administration guides and documentation relating to FortiOS 7.6.6 releases.

Domain Study Guidance

What is Next Generation Firewall: Study Guidance

This domain covers what a Next Generation Firewall is in detail and explains how it is utilized to protect networks, vital applications, and services from various emerging cyber threats.

  • Describe what a Next Generation Firewall is
  • Protect networks, applications, and services

How Firewall Policies Work: Study Guidance

This domain explains how the main features of a Next Generation Firewall work in practice, detailing firewall policies and how traffic rules are enforced across the enterprise infrastructure.

  • Explain main NGFW features
  • Understand firewall policies and traffic handling

User Authentication in NGFW: Study Guidance

This domain focuses heavily on user authentication mechanisms within NGFW environments, ensuring that network administrators can properly control access and verify user identities before granting network privileges to individuals.

  • User authentication mechanisms
  • Identity management and access control

Blocking Malware: Study Guidance

This domain addresses specific techniques for blocking malware using built-in security profiles, protecting organizational assets from malicious software infections, potential system disruptions, and unauthorized data compromises across all connected internal systems.

  • Malware blocking mechanisms
  • Security profiles and threat mitigation

Controlling Web Access with Web Filtering: Study Guidance

This domain covers controlling web access efficiently with web filtering profiles and categories, allowing organizations to enforce acceptable use policies and restrict visits to dangerous or unauthorized websites.

  • Web filtering implementation
  • Web filter profiles and category management

Intrusion Prevention System and Application Control: Study Guidance

This domain examines Intrusion Prevention Systems and application control signatures, providing students with the knowledge required to detect and block malicious network traffic and unauthorized application usage effectively throughout the enterprise network.

  • IPS and application control
  • Signature detection and prevention techniques

Connecting Multiple Locations Securely: Study Guidance

This domain explores advanced methods for connecting multiple organizational locations securely, ensuring reliable data transmission and encrypted communication channels across distributed enterprise branch offices without compromising overall network performance or data privacy standards.

  • Multi-location secure connectivity
  • Branch office security and encryption

Secure SD-WAN: Study Guidance

This domain explains how secure network models and technologies like SD-WAN and SASE enhance cybersecurity posture across modern distributed enterprise environments while maintaining high availability and seamless connectivity.

  • Secure network models
  • SD-WAN and SASE technologies

SASE: Study Guidance

This final domain covers modern SASE architecture and cloud-delivered security services, illustrating how converged networking and security features protect mobile users and modern cloud applications across all operational deployment scenarios.

  • SASE framework
  • Cloud-delivered security services
